# CREW — посещаемость, оплаты, группы

Рабочее PWA-приложение для студии CREW (брейкинг и ОФП). Статический сайт без сборки: HTML, CSS и JavaScript без библиотек.
Данные хранятся в вашей Google Таблице, связь идёт через Google Apps Script (адрес и ключ вводятся в приложении: Ещё → Настройки).

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Каркас страницы, подключает стили и скрипт |
| `styles.css` | Все стили приложения |
| `app.js` | Вся логика: экраны, связь с таблицей, офлайн-очередь |
| `sw.js` | Service Worker: быстрый запуск и работа без интернета |
| `manifest.json` | Установка на экран «Домой» |
| `assets/design-tokens.css` | Фирменные цвета, радиусы, тень |
| `assets/*.svg` | Знак, логотип (тёмный и светлый), иллюстрация пустого списка |
| `icon-*.png`, `apple-touch-icon.png` | Иконки приложения |

Все пути относительные, поэтому сайт работает и в подпути GitHub Pages (`https://имя.github.io/репозиторий/`).

## Публикация на GitHub Pages

1. Откройте репозиторий на GitHub и нажмите **Add file → Upload files**.
2. Перетащите **содержимое** папки (не ZIP и не саму папку): `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.json`, папку `assets`, все PNG. Файлы должны лежать в корне репозитория.
3. Нажмите **Commit changes** (ветка `main`).
4. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
5. Во вкладке **Actions** дождитесь зелёной галочки «pages build and deployment», затем откройте адрес сайта.

## Как убедиться, что обновление дошло до телефона

1. После публикации откройте приложение с интернетом. Новая версия скачивается в фоне.
2. На главном экране появится плашка **«Вышла новая версия приложения — Обновить»**. Нажмите её, приложение перезагрузится уже с новыми файлами. Если плашки нет, закройте приложение полностью и откройте снова.
3. Проверка на компьютере: Chrome → F12 → Application → Service Workers должен показывать `activated`, а в Cache Storage должен остаться один кэш с текущим номером (сейчас `crew-v6`).
4. Установка на iPhone: Safari → «Поделиться» → «На экран Домой». На Android: меню Chrome → «Установить приложение».

### Правило для разработчика
Любое изменение `index.html`, `styles.css`, `app.js`, иконок или `assets/` требует увеличить номер в `sw.js` (`var CACHE = 'crew-v6'` → `crew-v6`). Новый кэш собирается целиком и только потом заменяет старый, поэтому файлы разных версий не смешиваются.

## Офлайн-режим
- Интерфейс открывается без интернета.
- Последние загруженные данные хранятся на устройстве. Данные таблицы Service Worker не кэширует.
- Отметки, оплаты и правки без связи попадают в очередь и уходят в таблицу сами, строго по порядку. Сколько ждёт отправки, видно в плашке вверху.
- Если таблица отклонила запись, она остаётся в Настройках, в блоке «Не ушло в таблицу».

## Отметка посещаемости
Один тап ставит отметку. Чтобы снять, нужно нажать дважды: первый тап подсвечивает кнопку тёмным, второй в течение 1,8 секунды снимает.
